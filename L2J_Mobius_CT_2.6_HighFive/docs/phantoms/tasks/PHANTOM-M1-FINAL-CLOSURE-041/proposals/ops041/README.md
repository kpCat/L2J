# Исходники изолированных испытаний TASK041

Это исходники реально использованного коллектора, оркестрации и offline валидаторов. Они не включаются в обычный запуск поставки М1. Для воспроизведения их копируют в собственный `<HighFive>/.phantom-local/ops041` с сохранением подкаталога `validation`; корневые вычисления скриптов рассчитаны именно на это размещение. Отчёты всегда создаются в новом пространстве `evidence` задачи041.

После размещения `Build-StockShutdown041.ps1 -JavaHome <JDK25>` собирает shutdown helper из сохранённых Java исходников. Он повторяет production operator паттерн с отдельной строгой allowlist тестовых схем041, проверкой root/роли/runtime и вызовом штатного shutdown. Старые private бинарники не требуются. Production allowlist и040a не меняются.

JDK25, Python3 и штатный MariaDB client являются явными установленными зависимостями. `Control032.ps1` использует отслеживаемые `AttachContract024.java` и `ReadDurable024.java` из пакета024; исторические исходники не изменяются. Тестовые runtimes, копии схем, геоданные, учётные данные и закрытые raw архивы не входят в Git. Они не подменяют production source.

Коллектор фиксирует исходные байты полных native событий, закрывает ZIP с одним `records.jsonl` и сохраняет исходные ограничения размера и количества. `raw_archive041.py` проверяет SHA, CRC и количество записей до offline декодирования. `complete_chain041.py` последовательно проверяет все реальные границы commit через неизменённый checker039, порциями в его исходном лимите4096; операция не создаёт недостающие свидетели.

`Run-Crash041.ps1` относится только к новым собственным041x72/041x73. Негативные guards должны пройти до вооружения. Наличие скрипта или разрешения не означает выполненную аварию либо PASS. Recovery, повторный fault-off boot и полная semantic проверка обязательны. Обычная поставка использует отдельные отслеживаемые `tools/phantom-runtime`, без тестового коллектора и crash режима.

Состояние gate определяется отчётом TASK041 и фактическими результатами. Личная приёмка остаётся обязательной; М2 автоматически не запускается.
