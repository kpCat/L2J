# Scope discipline
Max10 existing production modifications listed CONDITIONAL/MODIFY plus≤2 optional helpers.
CONDITIONAL требует own first-cause/RED, не разрешение rewrite всей области.
BackgroundTransaction read-only: resolver уже умеет before/after. Если внутри него доказана
новая ошибка, вне согласованного routing/control дизайна, сохранить exact negative proof
и BLOCKED_DESIGN. Не обходить её manual SQL или другим writer.

Не менять NativeEvidence caps/semantics, global ThreadPool, EventDispatcher, NPC/Player AI,
Reward formulas, schema, data catalog, guard metadata. На этой задаче новый tactical AI не нужен.
Тесты:≤2 новых suites+≤4 existing exact affected paths из table. Дополнительно максимум2
маленьких isolated-lane/test helper по существующему шаблону, exact ledger before commit.
Если указанный test path отсутствует, прочитать реальное расположение и зафиксировать map
исправление только для test path; не устраивать research default branch.

Артефакты задач не входят в production cap, но thin runtime wrappers≤3; улучшение существующего
task-local observer/collector допускается отдельным diff. Не генерировать script per edit.
Source excerpt/type proposal не копируется в product автоматически: проверить API и RED.
