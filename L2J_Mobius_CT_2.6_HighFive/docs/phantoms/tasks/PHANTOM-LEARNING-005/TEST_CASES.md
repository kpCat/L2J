# TEST_CASES — дешёвые тесты прежде дорогих запусков

## Pure / unit / DB-free
- T01: stock/learned pair identity, scenario fingerprints/facts equal; adjusted gear/jewelry/skill, initial HP, level or mob instance => UNMATCHED (no metric delta).
- T02: source vs B policy wrong SHA/status/DRAFT8 => fail-closed before native CUT; model1 and model2 exact accepted readback/pass.
- T03: reversed A/B order, independent actor/target epoch and seed retained; same policy negative control -> no `policy divergence` even if native stochastic damage differs.
- T04: one incomplete or skipped side -> no matched completed pair; report attempt denominator and no cherry-picking.
- T05: two Party player kill receipts same NPC/spawn/instance -> unique enemy kill exactly one; exact EXP member credits retained separately.
- T06: a single positive damage event != complete fight; `UNKNOWN` loot/deaths/full DPS not zero; negative/failed cast not a successful impact.
- T07: native duplicate eventKey/armId/replay => idempotent or integrity error; no second credit; malformed JSON/SHA/provenance fail.
- T08: same held-out evaluation events never silently enter V3 TRAIN/TUNING/AUDIT used in model admission; no contamination.
- T09: Russian statistical output n=4 marks INCONCLUSIVE even if B faster in all; `ADVANTAGE_SUPPORTED` demands predeclared independent power and no safety regression.
- T10: no per-actor Thread, no hot network/SQL/mocked RNG; should be visible in focused diff/review.
