# Кандидат DRAFT для рецензии

Это реальные веса алгоритма 2: директор обучал модель на 22 TRAIN-примерах,
выбирал эпоху по 37 TUNING-примерам и проверял результат по 15 независимым AUDIT.
Все 74 события подтверждены как NATIVE. Выбрана эпоха 55; SQL readback подтвердил
12 500 байт и SHA-256 из `metadata.json`.

Статус **DRAFT**: в Solo MSE 0,139475 хуже независимого constant baseline 0,129114.
В Party MSE 0,079316 против baseline 0,082035. Обязательное условие улучшения
обоих направлений не выполнено. Модель не принята и не применена.

`weights.bin` и `metadata.json` предназначены для проверки результата обучения.
`runtimeApplicable=false`; наличие этих файлов не создаёт ACCEPTED checkpoint.
Команда `TRAIN_EXPORT.cmd` экспортирует только подходящую принятую TEST-модель
и при её отсутствии сообщает причину отказа. Применение в рабочей игре не выполняется.
