**LEARN-001** — SUCCESS in narrow verified scope: shared MLP, real Solo/Party PvE skill choice, NATIVE exact damage, offline train, accepted v2, cold load, actual cast difference. Legacy TASK130 remains PARTIAL.

**LEARN-002** — current task: first autonomous director and durable training pipeline with scenario diversity, native episodes, SQL episodes, headless scripts and self-runner without Codex; baseline class diversity/situation coverage. Not universal tactical intelligence yet.

**LEARN-003** — richer entity/action state and multi-step action policy: Heal/Resurrection, buff/debuff/control/sleep/root/stun, kite/reposition, summon & servitor, defensive/limit/transformation, team focus and priority, selected legal actions; separate per-role and per-mode reward, survival and economic outcome; upgrade network to several MB and retain raw episodes across schema versions; compare CPU and RTX A5000 offline training. Avoid reimplementation stock mechanics.

**LEARN-004** — self-play leagues and native PvP/PK, 1v1, 1vParty, Party-v-Party, stronger model and GPU batch simulation only when calibrated to actual Mobius game; automatic per-class/level/equipment/terrain coverage reports, validation promotion and model package to main with rollback, perf under >=128 visible. Owner decides deployment.

**Game feature tasks:** TASK130 preserved PARTIAL, not silently marked FULL; 131 Party PvP/PK and spoil mechanics, 132 clan native leader law, 133 raids/instances, 134 sieges, 135 TW, 136 Olympiad. Learning controller extends to modes after gameplay feature is genuinely ready. Keep separate code owner contracts; no goal can assume training alone fixes broken Party/STORE/Claim infrastructure.

**Do not equate** small MLP weights to complete AI knowledge. Raw episode events, game catalog and native ability dispatch are stable interface for future architectures. Model upgrade can learn by replay or distillation, not blind copy weights.
