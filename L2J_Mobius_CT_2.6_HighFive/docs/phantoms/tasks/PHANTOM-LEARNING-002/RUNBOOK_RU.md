# Операторское руководство — требуемые команды после реализации

Это **спецификация**, а не обещание, что команды уже существуют. Codex обязан реализовать и проверить по-настоящему.

- `TRAIN_START.cmd` — запустить собственную isolated тренировку с безопасными defaults. Повторный вызов показывает текущий статус, второй директор не создаёт. Самостоятельно проверяет SQL/Geo/ports и ownership. Сразу возвращает управление консоли, директора оставляет работать.
- `TRAIN_STATUS.cmd` — run id, состояние, время, количество реальных эпизодов, категории классов/NPC/экипировки, NATIVE samples Solo/Party, успешные/отклонённые сцены и причины, checkpoint version, принято/DRAFT, CPU/SQL, last heartbeat, ограничения.
- `TRAIN_PAUSE.cmd` — перестать запускать новые эпизоды, безопасно закончить текущий и сохранить checkpoint.
- `TRAIN_RESUME.cmd` — возобновить с прежнего cursor без дублей.
- `TRAIN_STOP.cmd` — штатно завершить именно свои процессы и освободить порты, сохранить все данные.
- `TRAIN_REPORT.cmd` — создать читаемый RU отчёт .md/JSON и журнал независимых проверок.
- `TRAIN_EXPORT.cmd` — только доказанная модель, формат/схема/SHA/quality, без приватных аккаунтов/SQL. Отсутствие модели сообщать как reasoned non-success.

Один установленный каталог `training/` либо разумный `tools/phantom-runtime/training/`. Работает из любого cwd, пути приводятся к absolute, config и scripts versioned. Экран необязателен, GUI в 002 не требуется. Игровой сервер и тренер — отдельные процессы; сам GameServer может выдавать на порту только loopback. Ноутбук должен оставаться включённым и не переходить в спящий режим.

Порядок пользовательского применения:
1. Вечером `TRAIN_START.cmd`.
2. Утром `TRAIN_STATUS.cmd`, затем `TRAIN_REPORT.cmd`.
3. При необходимости `TRAIN_PAUSE.cmd`/`TRAIN_STOP.cmd`, а качественную модель — `TRAIN_EXPORT.cmd`.
4. Никаких ручных SQL, копирования GeoData, редактора Codex, подтверждения каждой сцены, повторного ввода секретов или удаления каталогов.

Не считать сверхбыстрый отчёт о synthetic rows обучением. Сбор должен быть на настоящем GameServer. `TRAIN_REPORT` показывает не только число решений, но и подтверждённые игровые изменения и ошибки.
