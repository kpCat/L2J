# DATA MODEL — Goal 010

Entities:

```text
Node: stable area/hierarchy
Anchor: stable semantic point
Edge: stable adjacency/travel/perception relation
```

Node kinds cover regions, cities, outdoor areas, dungeons, catacombs, rooms and
corridors.

Anchor roles cover city center, respawn, shop, warehouse, Gatekeeper, farming,
route, room center and door sides.

Edge modes cover walk, passage, door, Gatekeeper, teleport and background.

XML schema version is 1. Semantic collections are immutable, canonical-sorted
and included in a deterministic SHA-256 snapshot hash.
