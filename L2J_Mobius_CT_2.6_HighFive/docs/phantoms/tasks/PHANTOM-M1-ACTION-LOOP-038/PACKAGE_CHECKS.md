# Проверка пакета

MANIFEST.sha256 охватывает все файлы пакета, кроме самого manifest.
`python tools/verify_packet038.py --test-proposal` проверяет bytes и компилирует
изолированный Java proposal во временный каталог, не в bin сервера.

Это НЕ GameServer test и не OLD RED исходного проекта. Предложенный policy может быть
использован как небольшой фрагмент реализации после native integration; сам по себе
он не доказывает существование пути, завершение каста, сохранение или M1 GREEN.

Пакет не содержит production overlay: распаковка добавляет только папку task038.
Внутренний прототип не зависит от gdx-ai/Recast и не вводит новый сетевой протокол.
Текущий source/MariaDB/native-runtime код пользовательского компьютера здесь не запускался.
