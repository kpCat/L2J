- Сначала реально прочитать локальные файлы архива задачи, текущий GitHub и AGENTS. Не полагаться на пересказ, не продолжать старый диалог предыдущих целей. Мышление Extra High, русский.
- Как требует root AGENTS, до изменения исходников показать владельцу короткий, точный `IMPLEMENTATION_PLAN016.md` и спросить **одно** подтверждение общей архитектуры/allowlist. После одобрения работать автономно; не спрашивать рутинных подтверждений на каждый тест.
- Разрешены scoped Git commit/push в `feature/phantom-world` в рамках этого Goal. Приватные local models/SQL/inventories никому не публиковать.

- После завершения требуется финальная владельческая приёмка, Codex не имеет права объявлять owner acceptance сам. В ответе дать ссылки на опубликованный GitHub commit и документы, точные budgets, успешные/незакрытые G0–G8.
