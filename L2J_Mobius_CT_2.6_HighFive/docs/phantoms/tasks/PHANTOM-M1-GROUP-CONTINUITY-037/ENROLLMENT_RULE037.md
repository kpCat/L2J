# Предварительное правило final037

Выбор окна использует фактическую геометрию, календарь и native admission. Не используются
будущие damage/reward/CONTINUITY PASS. Denominator сохраняет всех фактически enrolled.

Исходный observer036 в Talking Island village оказался в region delta3 от farm20120.
Диагностический ingress6 у самой farm сохраняет все восемь alive, но несколько участников
теряют общие цели до impact; этот probe не является acceptance.

Для finalA/B заранее выбирается независимая локаль Orc Village: текущий READY профиль66,
точка(-50845,-113715,-168), instance0. В полном pre-start census эта группа имеет27 READY
calendar-online фактических кандидатов в одной точке;66 доступен до23:13Z. Это выбор
пространства до результатов, не выбор удачных ID. Ни его handoff status, ни historical
readiness не предоставляют admission. Production guards решают фактическую материализацию.

Нативный synthetic initial point получается существующим read-only resolver до World
publication. До START выполняется тот же exact READY/calendar/geometry guard. После
bounded60с setup все natural World actors входят в cohort:6–8, ни один ID не исключается.
Любой календарный boundary внутри380с+30с отклоняет всю группу до measurement;
все кандидаты/причины сохраняются. Календарь, clock, geo, NPC/rates/population не меняются.

Два primary до измерений: lowest-ID actual native caster, затем lowest-ID другой eligible
участник. Две независимые базы037b/c, один committed Jar/config/catalog/observer/evaluator,
по380с, неподвижный observer, без breakpoints. Любая смерть/absence/смена epoch остаётся FAIL.
