# TASK037 — продукт и пределы

Нам нужны не отдельные удачные касты, а несколько обычных native Player, которые сами
выбирают подходящих мобов, передвигаются, наносят штатный урон, получают native награды,
переходят к следующей цели и восстанавливают работу после локального отказа.
Режим не должен превращать шесть независимых персонажей в новую party: «группа» здесь
означает cohort наблюдения, не объект Party. Совместные атаки разрешены.

Область: intent → local travel/start → AutoPlay/AutoUse → временный pause/replan → полезный
native progress. Исправлять общую причину, а не вводить специальные if(profileId==173).

CONTINUITY_V2. Для отдельного stable-farm gate заранее выбирается подходящее естественное
календарное окно (см. RUNBOOK), без дальнейшего изменения расписания/clock.
