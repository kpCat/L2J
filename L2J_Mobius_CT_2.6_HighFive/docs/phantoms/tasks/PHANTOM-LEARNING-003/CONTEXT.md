# Пожелания владельца, которые нельзя потерять

- Цель: настоящие игрокоподобные фантомы, а не декоративные NPC и не одни MODEL PASS.
- Уже 5000 долговременных профилей, >=128 реально видимых ботов + 250 offline merchants сверх этого cap. Не обучать 5000 сетей — общие веса, индивидуальное состояние и роли.
- Встреча лучника 61 и мага 68+ критически зависит от weapon/armor/jewelry enchant/grade, skills magic level, debuffs/buffs и resist. Обучение должно обобщать реальную асимметрию, а не фиксировать победителя по классу.
- Cardinal/Bishop с многочисленными Heal/Resurrection; Prophet со sleep/root/MP burn/cancel; dagger backstab, archer kiting, mages distance, Destroyer/Frenzy/Zealot, Tyrant limits; Cat summoner ведёт два тела, heal/UD/re-summon/cancel effects. Играть по штатным High Five правилам, с шансами и откатами.
- PvE смысл — EXP/SP, loot, Adena, Spoil/Sweeper, Shot расход, смерть; это нужно для будущего reward и нельзя отключать.
- Party по уровню предпочтительнее на старших, но роли tanks/support bypass solo viability, DD должны быть способны; правила внешние конфиги. Не менять политику партий ради HEAL теста.
- Может бежать/отступать и умереть; не создавать абсолютный запрет на риск. Критические технические инварианты leases не обходить.
- После завершения Codex отчёта ChatGPT **сверяет не только слова Codex, но и фактический GitHub SHA/code**. Каждый новый Goal — новый диалог Codex; для этой задачи один самостоятельный package и HANDOFF.
- Ручную проверку TRAIN_*.cmd пока отложить; никакой обязательной операции владельца до предоставления результата Codex.
- Большая самостоятельная русская semantic LLM и обучаемая навигация задуманы, но позднее, после боевого AI. GPU A5000 16GB/128GB RAM; GPU полезнее для batch training than per-tick inference; разрешение на отдельный CUDA pipeline позже.
