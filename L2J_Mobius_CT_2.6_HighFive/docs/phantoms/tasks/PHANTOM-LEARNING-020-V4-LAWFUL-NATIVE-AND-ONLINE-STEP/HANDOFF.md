# Результат пользователю: коротко и проверяемо

**В ответе Codex обязательно:**
- STATUS: FULL020 или точный PARTIAL/BLOCKED, ручная приёмка `REQUIRED`.
- Версия branch HEAD + ordinary push + independent GitHub readback, scope paths.
- Факт LIVE: какой source сцены, какой класс/навык, как был допущен NPC/владелец, stage CUT, `MODEL_CONSULTED/REORDERED`, stock/chosen и score, реальный paid HP/MP, event/episode SHA; без публикации приватных ID.
- Факт V4: исходный checkpoint 161 updates и SHA; new fresh TRAIN count, updates after, immutable SHA, independent cold pass, zero replay/double credit. Если changed score без changed choice — явно разделить.
- Безопасность: OFF/fallback, no unexpected production changes, old SQL/protected/Geo/selected/Adam/pointer/preserved history, owned processes/ports after shutdown.
- Стоимость: wall, GS starts/runtime, max duration каждого теста, sum checks и warnings. Если отклонение — честно указать.
- Что **не** входит: ночь/таймер8h, PvP, танки/HEAL/control/debuff, рост реальной эффективности над stock; Goal021 не запущен.

При POST PUSH проверять все изменённые исходники через GitHub, а не только свой RESULT. MANUAL gate закрывает владелец. Сразу новую задачу не выдавать. Если проект застрял на lawful scene — не обещать гарантированный быстрый фикс: привести причину, факты и максимум два решения.
