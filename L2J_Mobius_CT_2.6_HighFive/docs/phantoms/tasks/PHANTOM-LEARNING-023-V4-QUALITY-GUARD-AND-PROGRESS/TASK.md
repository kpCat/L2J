## Сделать
A. **Качество ≠ обновления:** добавить versioned `QualityGuard023` к текущим sealed TRAIN/TUNING/AUDIT и stage boundaries: frozen policy, immutable decision receipts, proven checkpoint source, отсутствие replay credit. Наличие `TUNING` и `AUDIT` в config не равно успешной независимой оценке. Baseline-only eval не может доказать, что V4 сильнее stock/лучшего checkpoint. При недостатке законных сопоставимых наблюдений статус `INSUFFICIENT_EVAL`.
B. **STOP/Pause до следующего GS**: проверять quality/admission до резервирования следующего native boot и после committed step, с консервативным лимитом новых TRAIN rounds без аутентифицированной оценки; default граница — текущий план 6 TRAIN и затем TUNING/AUDIT (не мешать eval rounds), после цикла без сравнимых model receipts остановка `PAUSED_EVAL_COVERAGE_GAP`. Для реальной подтверждённой регрессии — `PAUSED_REGRESSION`; для ≥3 **валидных** оценочных окон без доказанного прироста — `PAUSED_NO_SUPPORTED_GAIN` (но НЕ считать отсутствие данных за три плохих оценки). Нехватка данных, смерть/критическое ухудшение или tamper — только fail closed; нельзя просто продолжать TRAIN из-за роста updates. Не объявлять однозначную регрессию по одному бою.

Сохранять immutable кандидатов и lineage. Отдельный candidate/best-verification receipt — только при настоящих независимо сопоставимых наблюдениях; нельзя молча перезаписывать `ActionContinuationV4` HEAD или сбрасывать event keys.
