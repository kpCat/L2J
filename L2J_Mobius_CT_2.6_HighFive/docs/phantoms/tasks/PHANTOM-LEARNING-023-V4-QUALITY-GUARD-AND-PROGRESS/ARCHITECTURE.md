## New versioned boundary
- `QualityPolicy023` immutable per new campaign (opt-in for future campaigns; when old session already active, do not modify sealed config silently): schema, reference model/HEAD, thresholds, guard budget, baseline episode provenance, eligibility/splits. Default strict, TEST only, NO_AUTO_PRODUCTION_PROMOTION.
- Quality reducer consumes **authenticated evidence with provenance** from canonical native samples/episode + exact frozen split, candidate/model SHA and source SHA. An untrusted `status022.json`, UI text, a self-declared `audit=true`, fake JSON or manually pasted numeric metrics **cannot** by themselves grant `SUPPORTED_IMPROVEMENT`. If native heldout/candidate-vs-reference comparisons are missing, `QUALITY_UNPROVEN` and any benefit statistic remains UNKNOWN.
- Phase states: `COLLECTING` -> `EVAL_PENDING` -> `IMPROVEMENT_SUPPORTED` / `EVAL_INSUFFICIENT` / `REGRESSION_SUPPORTED` / `PLATEAU_SUPPORTED`. Only `REGRESSION_SUPPORTED` stops as proven regression. `EVAL_INSUFFICIENT` pauses on coverage; no false degradation inference. Later new evidence may resolve. A critical integrity/owner regression always BLOCKED.
- Default guard: max6 new genuine TRAIN rounds before the matching TUNING/AUDIT boundary. Allow scheduled heldout collection; after it, **before next TRAIN/native boot** require verified independent comparison, otherwise `PAUSED_EVAL_COVERAGE_GAP`. If even scheduled heldout is absent or non-comparable, pause earlier at next legal boundary; do not wait for 480min. `3` windows patience only when each has authentic comparable evaluation; missing windows do not increment patience.
- Set `baselineReferenceSha` to model216 SHA but label `REFERENCE_ANCHOR_UNEVALUATED`, not `BEST_VERIFIED`. Keep separate pointers `latestCommitted`, `referenceAnchor`, `bestVerified` (null until valid evidence) without rewriting `ledger/HEAD` or promoting production. A training model can worsen in TEST, but safety preserves the immutable reference and blocks uncontrolled further training; no promise of instant prevention of deterioration.
- Any future SUPPORTED verdict requires **genuine independent matched baseline/model/reference comparisons** (explicit sample count, strata, propensities, reasonable uncertainty interval, no safety/resource regression); benchmark thresholds must be explicit and frozen before viewing outcomes. Never turn per-action reward/MSE into causal win-rate; positive from n=1/2 or 0 MODEL divergences = INSUFFICIENT. If native V4 comparison requires a new evaluator, **do not** fabricate it in023; expose an explicit future dependency on Goal024.
- Guard consulted in controller before `reservation/boot`, after commit, and on recovery. Old campaigns retain their original semantics read-only; for a **new** campaign versioned owner policy must be explicit and commit once. If unspecified or conflicting guard -> STOP safely, not disable it. No hidden pause reset on Resume/Start/new-campaign after guard tripped; separate owner decision required and logged.
