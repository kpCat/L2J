# OBSERVATION

Observe up to four natural Phantom profiles for 10–15 minutes.

Record:
profile/object/epoch; positions; target changes; moving/attack/cast; native damage;
kill; EXP/SP; loot/pickup/autoloot where applicable; farmCycle sequence; idle reason/time;
water/wall/stuck; death/recovery if naturally observed.

Five-cycle PASS:
same Phantom lifetime completes five autonomous
`target -> damage -> kill -> positive EXP/SP -> next target`
cycles without operator combat actions.

Do not cherry-pick only successful actors.
