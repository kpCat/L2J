## Реализация и scope

- `SkillEquipmentFreedomConfig.java`, `ConfigLoader.java`, `Custom/SkillEquipmentFreedom.ini`. Один startup-переключатель, поставляемое значение True. False возвращает штатные ограничения.
- `SkillEquipmentConditions.java`, `ConditionUsingItemType.java`, `ConditionLogicNot.java`, `Skill.java`, `FuncTemplate.java`. Исходные деревья условий сохранены. Сервер выбирает условия без требований вида и хвата экипировки для владельца навыка из `Player`. Для stat-функций решение привязано к источнику эффекта при создании штатной функции. Входящий аргумент `Skill` при расчёте стата может обозначать атакующий навык. Исходные формулы, порядок операций, владелец функции и стек эффектов сохранены.
- `TriggerSkillByDamageDealt.java`, `EnergyDamage.java`. Сняты отдельные оружейные фильтры у изученного источника срабатывания. Десять ближних charge-навыков сохраняют коэффициент 77 на луке. Проверки события и расход зарядов проходят через штатный движок.
- `SkillEquipmentFreedomNative.java` и два отчёта. Исключение из обычного лимита 8–10 файлов ограничено тремя runtime-швами, startup-конфигом, одним native test и требуемой документацией. Writer (навыки, предметы, опыт) остаётся штатным. Новый runtime не пишет данные и не регистрирует дополнительных событий.

В [карте покрытия](GEAR-SKILLS-003-COVERAGE.tsv) 738 строк ветвей из 95 XML. Для 688 путей указан изменённый шов, для 50 зафиксирована штатная граница. Fish rod, предметные навыки, смена предмета и независимые условия остаются на штатном пути. Предметные template checks и `matchesItemType` сохранены. XML навыков и деревья обучения не менялись.
