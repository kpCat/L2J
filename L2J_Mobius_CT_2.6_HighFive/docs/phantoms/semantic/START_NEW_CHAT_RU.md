# Новый независимый чат

Прикрепите один актуальный `CHATGPT_GENERATION_RU.md`, экспортированный Studio или CLI.
«По паспорту создай 200 живых ответов про завышенные цены на эпик. Дай готовый файл .jsonl».
«По паспорту создай 200 входящих фраз про неудачную заточку, режим TRIGGER. Дай файл .jsonl».
«По паспорту создай инициативы только для зарегистрированного подтверждённого события. Дай файл .jsonl».
Полученный файл откройте в Studio: «Настройки → Импортировать файл ChatGPT / категории v4».
Нажмите «Проверить и просмотреть», изучите ошибки и примеры, затем «Принять в workspace» и «Собрать и проверить».
200 ответов дают 200 вариантов речи; распознавание входящих сообщений требует отдельного TRIGGER batch.
Для новой темы сначала зарегистрируйте проверенную категорию и экспортируйте обновлённый паспорт.
