# DR-04 — party-role capability matrix

Goal 013 различает capability и target scope, не назначая партийные роли:

| Capability | Проверяемое различие |
|---|---|
| heal / resurrection | восстановление HP и возвращение из смерти |
| recharge | восстановление MP |
| buff | обычный положительный эффект |
| song / dance | отдельные evidence skills |
| tank / control | aggro и control mechanics |
| damage | single-target или area scope |
| summon | отдельный servitor/pet/cubic actor |
| spoil / sweep / craft | отдельные механические capability |

Party lifecycle, вакансии, leader coordination и shared routes относятся к Goal 017. Rift относится к Goal 023, raid/epic — к Goal 026.

Источники: `Skill` effect/target facts, class skill trees и curated rules с точными skill ID.

Authority: `SERVER_LOADER_FACT` и `CURATED_CAPABILITY`. Confidence: `HIGH` для skill facts, `MEDIUM` для role mapping.
