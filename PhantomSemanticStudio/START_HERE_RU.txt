Phantom Semantic Studio — редактор внутри Phantom World

1. Открыть общий L2J repository на feature/phantom-world и прочитать ../AGENTS.md.
2. Открыть PhantomSemanticStudio.sln в Visual Studio с .NET10 Desktop development.
3. Запустить scripts/Build-Verify.ps1. После проверки приложение запускается через Start.cmd.
4. Источник по умолчанию — соседний L2J_Mobius_CT_2.6_HighFive; явная сохранённая настройка пользователя имеет приоритет.
5. Workspace остаётся вне L2J, в LocalAppData/PhantomSemanticStudio/workspace.

Исходное происхождение и SHA — IMPORT_ORIGIN.md. README_RU.md содержит сборки, ограничения Java-проверки и действующие сценарии. Старые checkpoint reports являются историей, не результатом новой сборки.

Рабочий Semantic Pack приложение не перезаписывает. XML stage и отдельный Java content-check не дают разрешения установки. Ни один инструмент TASK062 не запускает рабочий сервер или БД.
