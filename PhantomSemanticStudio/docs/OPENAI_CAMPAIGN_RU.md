# Кампании OpenAI в PhantomSemanticStudio

Настройки → Провайдер → OpenAI API → Открыть кампанию OpenAI. Панель использует официальный OpenAI Responses API. Инструменты PromptLab и редактура через LM Studio сохраняют собственные настройки и локальную привязку модели.

## Настройки и расходы

1. Введите ключ OpenAI в замаскированное поле. При необходимости нажмите «Сохранить ключ». При следующем открытии видно только состояние ключа. «Удалить ключ» удаляет локальную копию. Токен LM Studio вводится отдельно.
2. «Проверить соединение» делает запрос списка доступных аккаунту моделей. Успешная проверка каталога ещё не проверяет формат ответа или качество модели. Выберите точный идентификатор. Предложенный тариф GPT‑6.1 Terra относится к стандартной обработке короткого текстового контекста, проверен 20.11.2026. Сверьте ставки на официальной странице и отметьте подтверждение. Для другой модели введите её ставки за миллион токенов, включая ставки записи в кэш.
3. Введите доступную локальную квоту, оставьте резерв и задайте пределы на пилот, кампанию, сутки, месяц и запрос. Сутки и месяц считаются по UTC. Расчёт использует общий журнал Studio для разных workspace Windows-пользователя. Квота означает совокупное выделение для этой установки, включая уже записанные расходы. Фактическую доступность средств и источник списания проверяйте в OpenAI Platform. Автопополнение Studio не запускает.
4. Пробный расчёт включён при каждом открытии. Он позволяет строить планы и просматривать историю без генерации. Каждый Начать/Продолжить и платный пилот требуют явного подтверждения. Цена после ответа рассчитана из фактических полей usage и закреплённой ставки. Неизвестный исход занимает полный резерв.

- [Получение списка моделей](https://developers.openai.com/api/reference/resources/models/methods/list)
- [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)
- [Проверка цен](https://platform.openai.com/pricing/)
- [Тариф GPT‑6.1 Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra)

## Слепое сравнение и разрешение на кампанию

На вкладке кампании подготовьте калибровочный пилот. План включает восемь сцен по три реплики в каждом из двух форматов, всего 48 строк в 16 запланированных запросах. Действуют пределы до 2 USD, 60 строк и 20 запросов, включая ограниченные повторы подтверждённых отказов по частоте. Роли игрока и фантома, факты сцены, голос и категория одинаковы внутри пары. Формат JSON использует строгий объект V4. В текстовом режиме модель выдаёт отдельные строки, затем Studio присоединяет закреплённые метаданные и передаёт результат штатному валидатору V4. Взрослый контекст включается отдельно, для конкретной вымышленной приватной сцены согласных взрослых. Прочие сцены сохраняют свои границы.

В результатах оцените не менее 30 примеров, указав естественность русского, фактологию, роли, голос, категорию, согласие и разнообразие. Порядок примеров перемешан, формат и происхождение скрыты в таблице пилота. После ввода оценок можно явно открыть отчёт A/B со слабыми и сильными примерами, сценами, моделью, токенами и стоимостью. Для принятия выбранного варианта нужны также оценки обеих ветвей, независимые контрольные сцены, заданная доля проходов и отсутствие нарушения закреплённых фактов и ролей в оценённой выборке выбранного варианта. QUALITY003 остаётся исторической точкой сравнения со своими моделью и условиями.

Решение о качестве хранится отдельно от оценок строк и связано с их содержимым, версией промпта, моделью, форматом, реестром и порогом. Чтобы работать с другим профилем или обновлёнными оценками, примите новую калибровку. До этого массовый запуск заблокирован.

## План, журнал, результаты

«Построить план» распределяет цель по 142 листовым категориям V4. Для категорий доступны редактируемые квоты. Для пакета в 200 целевых уникальных валидных черновиков при микропартии 20 планируется десять запросов. Дубли и не прошедшие проверку строки не закрывают квоту. На хвосте объём запроса уменьшается. Микропартия 5–10 полезна, если длинный вывод выбранной модели нестабилен.

Новый план закрепляет речевую политику OpenAI v3. Сводка показывает взаимоисключающие квоты исходящих реплик GENERAL, STRONG и MATURE и отдельную квоту входов игрока TRIGGER. STRONG выделяется по ситуации и голосу для личного чата. В Party, Clan и Trade остаются уместные команды, резкие замечания и подколы в рамках правил публичного канала. Смысл категории и роли участников сохраняется при смене регистра.

MATURE выделяется только при включённом переключателе и только для заданных долей ответов в приватных сценах согласных вымышленных совершеннолетних. Политика охватывает двусмысленный юмор, приватный торг с пошлыми намёками, дерзкий флирт и разговор о близости и границах в контексте знакомства. Объём зависит от квоты категории. Разные стили двусмысленности и пошлого юмора получают собственные квоты. При выключенном переключателе квота MATURE равна нулю.

Кампании с исходным хешем v2 открываются как HISTORICAL. Можно просматривать сохранённые реплики, контекст из плана и хеши запросов, а также явно экспортировать исторический JSON для ручного просмотра. Экспорт создаётся отдельно от исходных файлов кампании. Рабочий запуск, запись оценок и приёмка профиля для v2 закрыты. При смене редакционной политики нужна калибровка с новым хешем. Изменения формулировок или маршрутизации требуют новой ревизии политики и нового хеша.

Пауза и остановка после подтверждения сохраняют результат текущего запроса. Продолжение из истории требует нового подтверждения расходов. При перезапуске сохранённый ответ дорабатывается локально. Если запрос мог быть принят провайдером, а достоверного ответа нет, дальнейшие запросы этой кампании блокируются до разбора истории. При падении качества, нехватке бюджета или диска, отказе по политике и проблемах с моделью приложение показывает причину остановки. Обычный лимит частоты даёт максимум четыре последовательные попытки, а длительное ожидание или неизвестный ответ ограничителя останавливают работу.

Результаты содержат раздельные числа созданных, валидных, уникальных, проверенных и одобренных строк. В журнале есть модель, запрос, статус, время, хеши сцены и промпта, usage и резерв. Рабочие JSONL сохраняются в частном каталоге кампании. Экспорт подтверждённых строк выполняется явно, до 100 одобренных строк на страницу, с проверкой штатным V4 импортом в режиме dry-run. Для дальнейшего импорта используйте существующий интерфейс V4. Сервер читает только установленный владельцем Semantic Pack.

Настройки и материалы находятся во внешнем рабочем каталоге Studio. Единственная сохранённая копия ключа защищена DPAPI Windows CurrentUser и проверяемыми ACL в %LOCALAPPDATA%\PhantomSemanticStudio\secrets. Скопированный зашифрованный файл может быть недоступен другому пользователю или на другом компьютере.
