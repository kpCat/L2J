## Пользовательский цикл и исправления

Из основного repository Release-приложение открывает исходную `studio-user-lab` через штатный --check-workspace: exit0. Computer Use не применялся; видимый ручной GUI smoke оставлен владельцу.

Исходная история скопирована побайтно в новый каталог;29 исторических файлов до/после совпадают по SHA256. Одна реальная коррекция `a9c74585...` COMPLETE, предложение `38c8f992...` осталось ReadyForGeneration=false до технической проверки. После проверки плана генерация `647d2c0b...` COMPLETE:4 строки. Качество слабое: «вместо пушки — кусок бесполезного хлама», снова «зато».

Новый ограниченный DESCRIPTION создал две отдельные GENERAL/REPLY-партии PvP и усталости. План проверен существующим diagnostic route, без owner acceptance. Генерации `374e5ef3...` и `bade0bd8...` COMPLETE, по 2 строки. Это интеграционный опыт, отдельно от партий калибровки 3–6 строк. «Реванш будет стоить тебе всех шмоток» показывает, почему технический COMPLETE не равен хорошей реплике.

Исправлены только два доказанных дефекта:

1. Без аргументов Program раньше всегда открывал LocalAppData без выбора. Теперь появляется стандартный выбор папки workspace, отмена завершает запуск. Явный --workspace и изолированный smoke-путь сохранены. Копирования истории и нового глобального хранилища нет.
2. Native Markdown-fenced JSON показывал голую английскую JsonException. Теперь отказ объясняет причину по-русски, сообщает о сохранённом ответе и новом отдельном запросе.
